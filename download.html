Pre-release · Release notes

Kite runs on Linux, x86_64. It's made for KDE Plasma 6 and works on other desktops too, without the Plasma integration.

AppImage

One file with everything bundled. Make it executable and run it.

Kite-0.9.0-x86_64.AppImage x86_64 

chmod +x Kite-*.AppImage
./Kite-*.AppImage

Install the AppImage into your menu

The repository comes with a script that installs an AppImage for your user, without root. Kite then shows up in the application launcher and can be set as the default browser in System Settings: 

packaging/appimage/install-appimage.sh Kite-0.9.0-x86_64.AppImage

This puts the AppImage at ~/.local/bin/kite and adds a desktop file and icon under ~/.local/share. To uninstall, delete those three files. Running the script again with a newer AppImage updates it in place, including copies managed by AppImageLauncher.

Rather not run a script from us? Any AppImage manager will do the same job:

  • AppImageLauncher: offers to move an AppImage into place and add it to your menu the first time you open it.
  • Shelly: the package manager on CachyOS, also in the AUR for Arch, which installs and updates AppImages too.
  • Gear Lever: a small app, available from Flathub, that adds AppImages to your menu and keeps them up to date.

KRunner needs restarting once to find Kite: systemctl --user restart plasma-krunner. The application launcher picks it up at your next login.
